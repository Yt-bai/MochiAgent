## 记忆
首先确定你要做哪些记忆

1. **短期记忆（short-term memory）**：当前对话的上下文记忆，比如用户对回答的约束、主要目标，最近几次对话的关键信息。

2. **工作记忆（working memory）**：Agent执行一个任务过程的中间状态，也可以理解为是observation，对环境变化的观察。

3. **长期记忆（long-term memory）**：保存跨会话还值得复用的关键信息（用户画像等）。

4. **外部知识记忆（knowledge memory）**：RAG。
