# 机器学习 Machine Learning
让模型从已有训练数据中“学出规律”，用来对新数据样本进行预测/分类/决策，而不是靠人为手写规则。


> 机器学习常见任务类别？

**监督学习、无监督学习、半监督/自监督学习**


> 机器学习常用方法？

- **监督学习：分类、回归（如逻辑回归、SVM、随机森林、XGBoost）**
- **无监督学习：聚类、降维（如 K-means、PCA）**
- **半监督/自监督：用少量标签或用数据本身构造监督信号**
- **强化学习**：奖励监督 / 反馈监督，**没有明确的正确答案标签，只有环境给的 reward（可能稀疏、延迟、噪声），学的是策略（怎么行动让长期累计奖励最大）**

其中，目前做各种机器学习的普遍通用框架就是**深度学习框架**，该框架的核心就是利用“多层神经网络（深度网络）”来学习特征与映射。

**一句话：DL=用深度神经网络做ML！**

因此，深度学习是一种具体的模型框架，贯穿于上面所有机器学习常用方法中！

---

> 因此，**强化学习**和**深度学习**都属于机器学习。

---

# 深度学习框架下的各种深度网络结构
- 擅长处理高维非结构化数据：图像、语音、文本、视频
- 通常需要更多数据和算力
- 端到端学习：减少手工特征工程

**典型模型：CNN、RNN/LSTM、Transformer、Diffusion 等。**

CNN 原理一句话：用卷积核在局部滑动做权重共享的特征提取，逐层把低级局部模式组合成更高级的全局语义表示。**VGG、ResNet、U-Net**

Diffusion 工作原理一句话：先按固定过程把数据逐步加噪到近似纯噪声，再训练模型在反向过程中一步步预测并去除噪声，从噪声还原生成数据。**U-Net、DiT(ViT)**

# 强化学习

只给问题(Prompt)和答案(Answer)，让模型自己学习推理过程。

PPO/GRPO算法要用到**奖励模型 Reward Model**。

**强化学习的目标是:最大化奖励，同时不要偏离原始模型太远。**


在强化学习领域，PPO(Proximal Policy Optimization)是最经典的算法之一。PPO 通过限制策略更新的幅度，保证训练的稳定性。但是，PPO 在 LLM 训练中存在一些问题:需要训练 Value Model(价值模型)，增加了训练复杂度和显存占用;需要同时维护四个模型(Policy Model、Reference Model、Value Model、Reward Model)，工程实现复杂;训练不稳定，容易出现奖励崩塌或策略退化。

GRPO(Group Relative Policy Optimization)[2]是一种简化的 PPO 变体，专门为 LLM 设计。GRPO 的核心思想是:不需要 Value Model，使用组内相对奖励代替绝对奖励;简化训练流程，只需要 Policy Model 和 Reference Model;提高训练稳定性，减少奖励崩塌的风险。

对于 LLM 训练，GRPO 是更好的选择，因为它更简单、更稳定、显存占用更低。
